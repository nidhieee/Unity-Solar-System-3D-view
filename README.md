# Unity 3D Solar System Simulation

A 3D planetary simulation built using the Unity engine. This project establishes foundational skills in C# scripting, game object hierarchies, material application, and basic physics/orbital mechanics. Developed as the introductory project for the **Michigan State University Game Design and Development Specialization** on Coursera.

## 🚀 Live Demo
You can play and interact with the build directly in your web browser here:
👉 **[Play on itch.io](https://ruin0105.itch.io/solar-system-ruin)**

---

## 🌌 Features
* **Orbital Mechanics:** Realistic hierarchical rotation (planets rotating on their axes while orbiting a central star).
* **3D Viewport:** Interactive camera allowing players to survey the scale of the system.
* **Custom Textures:** Styled planetary surfaces and space skybox environments.
* **WebGL Deployment:** Optimized build playable directly on the web.

## 🛠️ Built With
* **Engine:** Unity
* **Language:** C#
* **Platform:** WebGL / PC

## 📖 What I Learned
* Setting up parent-child relationships in Unity's Scene Hierarchy to handle complex rotations.
* Writing modular C# scripts for controlling translation and rotation speeds (`Transform.Rotate` and `Transform.RotateAround`).
* Managing build settings and optimizing assets for stable WebGL browser deployment.
